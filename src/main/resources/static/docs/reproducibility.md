# 随机种子、姓名语言与时间范围

[English](reproducibility.en.md)

每张生成表可设置 `generationSeed`（可选安全整数）和 `locale`（`zh_CN` 或 `en`）。在界面“行与关联”中配置，或直接写入普通方案／MCP 的 tables 配置；方案导入导出保留这些字段。

```json
{"name":"orders","size":100,"generationSeed":42,"locale":"en","columns":[{"name":"id","javaType":"java.lang.String","regs":[{"code":"FIX.UUID"}]}]}
```

种子按表名、列名、行号派生独立随机流，避免任务并发与同表引用的执行顺序改变结果；生成和无写入预览复用该机制。算法版本为1，跨版本复现应保留项目版本及完整方案。大小写归一后的表／列名称、种子、规则与行号相同，受支持的普通值可重复。仅更改列的排列不会切换其随机流。

支持 UUID、人名、手机号、数值／字符串／日期范围、加权输入、递增、普通引用、受限条件和树形规则。`locale` **只影响人名**：`en` 使用有限英文名／姓词表，默认中文名；不把手机号或身份证转换为其他国家格式。加权输入提供类别分布，固定输入和范围端点可构造边界样本；它们不保证小样本严格达到某个比例。

配置种子时，不支持的 `FIX.IDENTIF`、`REG.STYLE`／自定义正则规则明确报 `SEEDED_RULE_UNSUPPORTED`；条件表达式限无外部副作用的内置运算，不能偷偷调用系统随机数或当前时间。未配置种子的原有规则保持可用。只读来源表不生成新值，应用该模式会清除种子和姓名语言设置。

时间规则 `REG.DATE.dateRange` 使用明确的**绝对 epoch 毫秒起止值**，不自动取“今天”；保留相同范围及 JVM／数据库时区设置才能比较相同时间表示。系统任务时间、批次号和请求号仍独立生成，不能为了复现覆盖真实运行记录。

以下不由种子保证：

- 数据库已有候选内容／排序变化、默认值、自增列和触发器；冻结来源及排序后再复现。
- 字段扩展输出。扩展作者需要自行固定其参数、算法、外部依赖和时间；普通种子不会替任意代码提供确定性。
- 跨版本、跨时区、数据库精度转换及真实工作流的业务行为；继续核查结果。

相同种子会复现 UUID 等值，再次写同一张表可能主键冲突。**种子不是请求幂等**：超时后查原 requestId／batchId，不能换请求号重跑。要制作相同数据的对照实验，应使用不同空测试库或清理已确认的原批次。
