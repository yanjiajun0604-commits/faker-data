# 便携版说明

应用存储从 JPA/MySQL 改为 JDBC/SQLite；方案 API 字段保持兼容。SQLite 是应用内部状态库，和生成目标 JDBC 连接相互独立。旧 MySQL 方案库不会自动迁移，可在旧版本页面导出或重建方案；请保留旧库，避免遗漏连接配置和字段规则。

`LocalTaskService` 取代私有异步任务组件，固定线程池和有界 FIFO 等待队列负责执行；SQLite 只保存 ID、类型、状态、进度、结果、时间和截断后的错误描述。没有任务重放和分布式调度，也没有旧组件的动态优先级管理接口。当前主界面只使用 GEN_DATA 提交及进度查询接口。

`ReferenceCache` 隔离引用值存储，内存和 Redis 实现共用相同生成逻辑。内存模式保留 SQL NULL，达到容量限制时拒绝写入并回滚，不会静默返回被淘汰的引用值。Redis 对每个任务使用独立哈希、18 小时 TTL 和任务结束删除；若进程崩溃，由 TTL 回收。任务运行时，写入会刷新 TTL；不要在执行期间清理该 Redis 数据库。

默认端口 8085、仅监听 127.0.0.1。`run.cmd`、`run.sh` 首次构建后启动打包好的前后端，前端不固定端口。Redis 配置只在主动选择 Redis 模式时生效。

这次保留原有 Spring Boot、Vue 主版本和生成规则，重点是消除私有构建依赖、默认外部服务及发布缺项。SQLite 单写者适合本地方案/任务元数据；实际多任务吞吐受目标数据库、规则、批次、JVM 内存及引用规模共同影响，不能由缓存微基准直接推算。
