# 人工界面的高级配置

[English](manual-advanced.en.md)

连接测试数据库、选择表后，在“配置生成规则”页点击各表右侧的“行与关联”。原有规则、树形配置、方案“使用”按钮和中英文切换继续可用。

## 表的行来源

- **生成新行**：使用表的数据量或已有树形配置。
- **只读引用现存行**：选择候选字段，配置 AND 等值筛选、稳定排序和候选行上限。候选表不执行字段生成规则，也不写入或纳入新增批次清理。优先仅选择需要的标量字段；已有二进制字段不适合作为候选投影。字符串可直接输入；布尔值、数字、null 按 JSON 标量解析。大整数、精确小数或数字形式的业务编码用 JSON 字符串，例如 `"9007199254740993"`、`"001"`。
- **按父行展开**：选择父表、每个父行生成数量，以及可选父行条件，例如 `#state == 'SAVED'`。这里的字段来自父行。子行中实际关联 ID 仍需通过跨表引用规则配置。

树形配置与另外两种行来源互斥，切换前先关闭树形配置。表级容量、类型、字段和依赖的最终检查由后端预检及生成引擎完成。

## 虚拟字段与精确匹配

在“行与关联”中添加虚拟字段后，在展开的字段列表中为它配置普通规则。虚拟字段可用于角色标记、父键、条件和引用，但不写入数据库；只读候选表不支持虚拟字段。删除被引用的虚拟字段后，应修改依赖规则并重新预检。

在“引用字段 → 其他表字段”中，选择目标表列后，可用匹配助手指定“候选表字段等于本行字段”或“等于固定值”，点击“添加匹配”。下方 JSON 保留可编辑；同一个候选字段再次添加会替换该字段的匹配项。无匹配、多匹配的处理策略仍需明确选择。普通字段继续优先使用内置规则；仅对不能生成的字段，使用“字段扩展”中的已安装可信扩展标识和 JSON 参数。扩展不会随分享文件安装。

## 预览、预检和分享

“预览样本”以表格显示有限样本及虚拟字段，不写入目标库、不运行字段扩展。“数据库预检”检查元数据及可静态判断的值。两者不能证明完整数据量、数据库动态默认值、触发器或真实业务流程正确。完整诊断和限制可展开查看。

“我的生成方案”保留“使用”和“删除”，并提供“导出”和“导入分享方案”。导出不含连接信息，部分私有配置变为需本机绑定的占位。导入前在首页表单中填写本机连接，再粘贴分享 JSON，以及其 `requiredLocalValues` 指针对应的私有值对象；不需要私有值时使用 `{}`。有扩展或高级表达式时，审查内容后明确勾选信任。导入只保存，不自动生成；同名方案默认拒绝覆盖。私有值仅填写本机界面，不应发给 AI 或提交仓库。

分享前仍需检查业务名称和普通文本；脱敏不是任意个人数据识别。详见[分享契约](portable-schemes.md)、[预览与核查边界](preview-verification.md)。
