# Project overview / 项目概要

## 中文

faker-data 是一个本地运行的可视化测试数据生成工具。它不只生成随机字符串，还能让订单引用同批用户、让部门组成父子树、让字段按业务条件生成不同值。支持 MySQL、Oracle 和达梦目标库，提供字段规则、跨表引用、条件表达式、树形结构和可复用方案。下载一个 JAR 即可打开网页使用，界面支持中文 / English 即时切换并记住选择；应用默认不依赖外部 MySQL 或 Redis；也可让本地 AI 按指南通过 HTTP API 完成生成流程。适合接口联调、功能测试、演示和需要可控关联数据的开发场景。

## English

faker-data is a local visual studio for relational test data. Go beyond random strings: generate users and linked orders together, build parent/child department trees, and make field values follow business conditions. It supports MySQL, Oracle, and Dameng targets with reusable schemes, field rules, cross-table references, conditions, and tree generation. Run a single JAR to open the English/Chinese web UI; switch languages without losing your connection, rules, or task. Your language choice is remembered, and no external MySQL or Redis is needed for application startup. A documented HTTP API lets local AI agents drive the same workflow. Designed for API integration, functional testing, demos, and scenarios that need controlled relationships between synthetic rows.
