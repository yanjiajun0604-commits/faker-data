## 中文短介绍

我把自己的测试数据生成工具 faker-data 开源了：下载一个 JAR 就能打开网页配置规则，支持 MySQL / Oracle / 达梦；可以一起生成父子表、条件字段和组织树。还附了 AI 调用指南，让本地 AI 通过 HTTP 接口把需求变成测试数据。欢迎试用、反馈可复现问题，也欢迎贡献数据库兼容测试和英文界面。

项目：https://github.com/yanjiajun0604-commits/faker-data

## English short introduction

I open-sourced faker-data, a local visual studio for relational test data. Run one JAR, configure field rules in your browser, and generate linked parent/child records, conditional values, and trees in MySQL, Oracle, or Dameng. It also includes an HTTP API guide and runnable examples for local AI agents. I'd love feedback from people testing real relational workflows, especially database compatibility reports and reproducible edge cases.

Repository: https://github.com/yanjiajun0604-commits/faker-data
